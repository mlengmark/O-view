# What's new in v1.1.0, for someone upgrading from v1.0.0

This release is the clean-up after v1.0.0. Nearly all of the work moved code around so
that the Windows and Linux heads share more of it, and that changes nothing you can see.
The handful of things you would notice are below, and the list is short.

## The Windows meters match the icon in the light theme

The session and weekly bars on the Windows panel were painted from three shades of their
own, chosen for the dark theme, so in the light theme they came out paler than the tray
icon and the Linux panel for the same reading. They now take the same colour rule the icon
uses: a 72% reading is the same amber in the icon, on the Windows panel and on the Linux
panel, in either theme.

## The Linux token tile reads the same as the Windows one

Today's token tile on Linux carried a note, "incl. off-plan usage", that the Windows panel
never showed. Both panels now show the same tile. The note stays on the two value tiles,
where mixing plan and extra usage changes what the figure means.

## Smaller things

- **The weekly-reset dialog's buttons are the same height as the other dialogs' buttons.**
  They were two pixels shorter.
- **A few panel texts read with a comma or a colon where they used a dash.** The off-plan
  banner headings and the hint under the weekly-reset field are the ones you might notice.
  The wording is otherwise unchanged.
- **Two libraries moved to their maintenance releases.** The Linux head takes Avalonia
  12.1.4 and both heads take Microsoft.Data.Sqlite 10.0.13. Neither changes behaviour.

## For anyone reading the repository

- A new [overview page](../overview.md) shows every surface the app can draw, on both
  platforms and in both themes, with images the app rendered itself. The README opens
  with a gallery that links to it.
- The README and CLAUDE.md are rewritten in a plainer voice, a new
  [platform status page](../platform-status.md) says what has actually been seen working
  on each platform, and a new [command-line page](../cli.md) lists every flag.

## What's known not to work, or hasn't been checked

- **The very first Alt+arrow press right after clicking the panel's header still does
  nothing.** Nothing in this release touched it. The presses after that one move the
  panel as expected.
- **Nothing in this release was checked on a Linux desktop session.** The changes above
  were verified by the rendered-image comparison the test suite runs on every change and
  by CI's headless Linux job with a real session bus, not by a person at a desktop. What
  the v1.0.0 notes said about Linux checks still applies: the panel has been exercised on
  an Ubuntu 24.04 virtual machine under XWayland, not on Xorg since 2026-10-15, and never
  on physical hardware.
