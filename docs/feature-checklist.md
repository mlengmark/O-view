# Feature checklist

Everything O-view does today that a user would notice, and the test or golden image that proves it still works. A change that breaks any row here is a regression, whatever else it improves.

- **Proof** names tests as `Class.Method`. A golden image is named by its sample state (`tests/golden/<platform>/panel-<state>-<theme>.png`, from `src/O-view.Presentation/Samples/SampleStates.cs`).
- **Platforms** means where the feature exists today, not where it should.
- **"none yet"** marks a feature with no automated proof. It says what test would prove it; see Gaps.

`guard-ratchet` reads this file on every PR. It fails a PR that removes a feature, empties its proof, cites fewer tests for a feature than before, or cites a test that doesn't exist. So renaming a cited test means updating its row in the same PR. Adding features and proofs is always allowed.

## Gaps

Features with no automated proof, or proof on one platform only. Closing one means writing the test named in its row and replacing "none yet" with it.

- **F23:** the Windows icon's click-to-close toggle (400 ms window).
- **F24:** Windows Run at startup (the registry Run key).
- **F34:** read-only against Claude's files; nothing asserts that nothing is written.
- **F35:** no subscription credential handled; only the diagnostics bundle (F26) is tested.
- **F37:** 31-day history surviving transcript deletion.
- **F44 (Windows half):** following `AppsUseLightTheme` and re-reading it on open.
- **F45 (Windows half):** the mutex single-instance guard.

The Linux panel has no off-plan banner, off-plan section, tile flip, gridlines or graph hover cards (F12, F16, F17, F18), although `docs/ui-spec.md` makes the panel's content a shared contract. That is missing parity, not missing proof: when Linux gains them, the row's Platforms and Proof grow with it.
