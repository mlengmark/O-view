# Feature checklist

Everything O-view does today that a user would notice, and the test or golden image that proves it still works. A change that breaks any row here is a regression, whatever else it improves.

- **Proof** names tests as `Class.Method`. A golden image is named by its sample state (`tests/golden/<platform>/panel-<state>-<theme>.png`, from `src/O-view.Presentation/Samples/SampleStates.cs`).
- **Platforms** means where the feature exists today, not where it should.
- **"none yet"** marks a feature with no automated proof. It says what test would prove it; see Gaps.

`guard-ratchet` reads this file on every PR. It fails a PR that removes a feature, empties its proof, cites fewer tests for a feature than before, or cites a test that doesn't exist. So renaming a cited test means updating its row in the same PR. Adding features and proofs is always allowed.
